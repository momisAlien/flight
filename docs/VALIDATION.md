## 사용 흐름

로컬 Chrome과 격리된 가상 공급사로 검색 시작·중단·결과 보존·새 탭 기록 복원·실행 확인 취소·저장 조건으로 새 검색·완료 후 새로고침을 검사했습니다. 공급사 성공률 검증과는 별개입니다. 이전 실제 수집 결과의 왕복/편도 조합 각각 20개를 PC 1280px·모바일 375px에서 재생했고 가로 넘침·브라우저 오류가 없었습니다.

## 복수 공항·날짜 실조회

검증 실행 파일: `tools/check_multiroute_live.py`. 로컬 증거 파일명은 실행을 시작한 날짜인 `multiroute-live-20261010.json`입니다. 원시 결과는 개인 로컬 환경에 보관합니다.

조건: ICN·GMP → NRT·HND, 2026-11-10~11 출발, 5박, 성인 1명. 왕복·출국 편도·귀국 편도를 각각 조회했습니다.
